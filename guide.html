Orientation

How to Use the Solaris Ed Portal

A comprehensive guide for Senior High School TVL-ICT Animation students.

1. Using the Dual-Mode Lesson Viewer

For each lesson (Lesson 1 to Lesson 7) inside the Lessons page, you can choose between:

  • Full Version: Contains comprehensive, detailed, and in-depth explanations of each topic, including history and foundational theories.
  • Summarized Version: Contains quick and easy-to-understand bullet points, perfect for a quick review before exams.

2. Following the Curriculum Scope

It is recommended to follow the sequential flow of modules starting from Lesson 1 (History) up to Lesson 7 (12 Principles) to better grasp the foundations of digital and traditional animation.

Frequently Asked Questions (FAQs)

Do I need an internet connection to use this portal?

Solaris Ed is built using pure HTML and CSS. You can open and use it offline on your computer or mobile browser, except for the Font Awesome icons which load via a CDN.

How can I apply what I've learned from these lessons?

You can check the Software Tools section for recommended applications to use when creating your performance tasks and animation plates.
